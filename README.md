TripleLift is a programmatic advertising company specializing in native inventory. The platform provides a creative SSP (Supply-Side Platform) and exchange with REST and OpenRTB APIs for managing native ad units, deals, targeting, viewability measurement, and creative quality across web, mobile, and connected TV environments.

## APIs

- **TripleLift Exchange (TLX) API** — OpenRTB 2.x and Native Ads 1.2 real-time bidding API for demand partners (DSPs and buyers). Supports native, banner, video, and CTV formats with user sync, win notifications, and privacy compliance (GDPR, CCPA, SKAdNetwork).
- **TripleLift Supply Publisher API** — REST API (v1.0–v1.3) for publishers and supply partners covering publisher network reporting, CTV publisher network reporting, and integration management.
